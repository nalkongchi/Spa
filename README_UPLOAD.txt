SPA 45점 목표 5주 트레이너 · 표현 복습/전략 강화/소프트 블랙 아이스 버전

업로드 방법
1. ZIP을 먼저 압축 해제합니다.
2. 압축을 푼 폴더 안의 파일과 폴더를 GitHub 저장소 최상위(root)에 업로드합니다.
3. 기존 파일 위에 덮어써도 됩니다. GitHub에서 같은 경로의 파일은 새 버전으로 교체됩니다.
4. 최상위에 index.html이 있어야 합니다.

필수 구조
index.html
css/app.css
data/content.js
js/app.js
images/01.png ~ images/12.png
vendor/jszip.min.js

이번 버전 핵심 변경
- 같은 사진의 연속 질문을 하나의 자료 세트로 묶어 사진 DOM을 유지
- 자동 지연복습과 문제 강제 재출제 기능 제거
- 모의고사에서 같은 시각자료의 남은 질문이 약점 보강으로 다시 섞이지 않도록 처리
- 기록 탭을 재사용 표현 저장·분류·간격 복습 중심으로 개편
- 기존 받아쓰기·평가·녹음 기록은 접힌 ‘전체 학습 기록’에서 유지
- Week 완료 표시 위치와 첫 회차 카드 사이 간격 조정
- 기존 라이트모드를 유지하면서 소프트 블랙 아이스 야간모드 추가
- 테마 선택은 spa45-theme 키에 별도로 저장하며 운영체제 테마도 감지
- 자동 지연복습이 빠진 자리에 SPA 전략 강화 신규 문제 30개 추가
- 업무·기술, 취미·여행, 운동·건강, 한국문화, 자기소개, 가정 상황, 사진·그래프, 듣기 요약 전략 반영
- 신규 전략 문제의 재사용 표현을 수행결과 평가 화면에서 선택 저장 가능

데이터와 저장

주의
- images 폴더를 빠뜨리면 사진 문제가 표시되지 않습니다.
- 브라우저 TTS에는 실제 오디오 탐색 시간이 없어 끌어서 이동하는 재생바는 제공하지 않습니다.
- 실제 휴대폰의 TTS 일시정지·이어 듣기와 마이크 권한은 GitHub Pages 배포 후 기기에서 한 번 확인해 주세요.
- 이전 audio 폴더가 저장소에 남아 있어도 앱에서 참조하지 않으므로 작동에는 영향이 없습니다.
