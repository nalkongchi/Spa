이번 통합본의 핵심 변경

[수정 25 · 자가진단 개편]
- 긍정형 자가평가를 ‘이번 답변에서 걸린 부분’ 병목 진단형으로 교체했습니다.
- 공통 병목 7개와 문제 유형별 병목을 구분합니다.
- ‘답변 체감’을 ‘체감 난이도’로 변경했습니다.
- 난이도는 1 매우 쉬움 ~ 5 매우 어려움이며 답변 점수가 아닙니다.
- 선택하지 않은 병목은 문제가 없었다는 뜻으로 해석하지 않도록 프롬프트에 명시합니다.
- 이전 버전의 긍정형 자가평가와 답변 체감 기록은 삭제하지 않고 구형 기록으로 보존합니다.

[수정 26 · ChatGPT 전달 자료 고정]
- 개별 답변은 [SPA_APP_PACKET_V1] / 단일 답변 피드백 형식으로 생성합니다.
- 회차 종료 시 [SPA_APP_PACKET_V1] / 회차 종합 분석 형식으로 생성합니다.
- 회차·문제 ID, 참고자료, 받아쓰기, 녹음 길이, 수행 결과, 체감 난이도, 병목 진단을 일정한 순서로 전달합니다.
- 듣기 지문, 상황 원문, 그래프·표 수치, 제품 특징, 사진 절대주소를 문제 유형에 맞게 포함합니다.
- 녹음 파일 자체가 프롬프트에 첨부되지 않는다는 점을 명시해 발음·억양을 들은 것처럼 평가하지 않게 했습니다.
- 버튼 이름을 ‘이 답변 피드백 자료’, ‘오늘 회차 종합 자료’로 정리했습니다.

[수정 27 · 문제 순서와 주제 균형]
- 자기소개를 Week 1 평일 1의 첫 문제로 배치했습니다.
- 자기소개 전략 문제는 Week 1 평일 1에만 남기고 다른 회차의 중복 자기소개를 교체했습니다.
- 전략 문제를 일반 인터뷰 세 문제 뒤에 일괄 삽입하던 순서를 제거했습니다.
- opening, after-interview-1, after-interviews, closing 위치에 따라 회차 흐름에 맞게 배치합니다.
- 35회차, 일반 인터뷰 105개, 전략 문제 30개 구조는 유지합니다.
- 사용자가 지정한 기준 질문 10개를 모두 포함했습니다.
- 회사·자동차·엔지니어링 중심 질문 일부를 일상, 건강, 여행, 제품, 소비, 고객 경험, 한국문화, 일반 기술 의견으로 교체했습니다.
- 수정된 질문만 새 r27 ID를 사용해 이전 질문의 받아쓰기·평가·녹음과 섞이거나 덮어쓰이지 않게 했습니다.
- 모의고사는 실전 10문항과 선택 약점 보강 문항을 분리했습니다. 실전 종료 후 보강을 선택할 수 있습니다.


[수정 28 · 구조 정리 및 모바일 안정화]
- 제거했던 모바일 하단 고정 액션바는 되살리지 않고 빈 함수와 호출부만 정리했습니다.
- 문제 번호 화살표와 숫자 스크롤을 서로 겹치지 않는 독립 영역으로 재구성했습니다.
- 숫자를 흐리게 하던 좌우 페이드와 화살표 아래로 숫자가 비치던 현상을 제거했습니다.
- 모바일 0 / 0 배지를 실제 현재 문제 / 전체 문제 수에 연결했습니다.
- 기록 탭 ‘전체 표현’ 버튼이 두 줄로 갈라지지 않게 수정했습니다.
- 모바일 체감 난이도와 설정·백업 화면을 더 짧고 읽기 쉽게 정리했습니다.
- JSON 작업 버튼 3개를 모바일 한 줄에 배치하고 위험 구역은 접기형으로 변경했습니다.
- 표현 카드 수정과 삭제를 앱 내부 모달로 교체했습니다.
- 라이트·다크 디자인 토큰을 각각 하나의 변수 블록으로 통합했습니다.
- 사진 12장과 모든 사진 문제 데이터는 변경하지 않았습니다.

사진 문제 보호
- images/01.png ~ images/12.png 파일은 변경하지 않았습니다.
- 12개 사진의 제목, 배치 회차, 질문 문구, 질문 개수, 질문 순서, 그룹 구조를 변경하지 않았습니다.
- 사진 세트는 중간에 다른 문제가 끼지 않는 하나의 잠긴 블록으로 유지됩니다.
