SPA 45점 목표 5주 트레이너 · Speakflow 디자인/사진 자료 버전

업로드 방법
1. GitHub 저장소의 기존 파일을 모두 삭제합니다.
2. 이 폴더 안의 파일과 폴더를 저장소 최상위(root)에 그대로 업로드합니다.
3. 최상위에 index.html이 있어야 합니다.

필수 구조
index.html
css/app.css
data/content.js
js/app.js
images/01.png ~ images/12.png
vendor/jszip.min.js

이번 반영 범위
- 모바일 하단 고정 작업 바 제거
- 듣기 지문 TTS 재생 준비/재생/일시정지/이어 듣기/중지 상태 수정
- 밝은 스카이블루·라벤더 글래스모피즘 디자인 적용
- 사진형 SVG 12개를 images/01.png~12.png로 교체
- 사진형 후속 질문의 중복 제거 및 장면별 질문 구체화

주의
- images 폴더를 빠뜨리면 사진 문제가 표시되지 않습니다.
- 브라우저 TTS는 실제 오디오 파일이 아니므로 탐색 가능한 재생바는 제공하지 않습니다.
- 지문 TTS 버튼은 재생 준비 중 중복 클릭을 막고, 실제 시작 후 일시정지/중지가 활성화됩니다.
