수정 28 · 구조 정리 및 모바일 안정화

1. 제거된 모바일 하단 액션바 잔여 코드 정리
- syncMobileActionBar 빈 함수 삭제
- 남아 있던 호출부 전부 삭제
- 하단 고정 액션바는 다시 만들지 않음

2. 문제 번호 내비게이션 재설계
- 왼쪽 화살표 / 번호 스크롤 / 오른쪽 화살표를 독립된 3열 구조로 분리
- 화살표의 absolute 배치 제거
- 번호 위를 덮던 좌우 투명 페이드 제거
- 화살표와 숫자가 동시에 비치던 반투명 겹침 제거
- 화살표와 번호 버튼을 44×44px 터치 영역으로 확대
- 스크롤 가능 여부에 따라 좌우 화살표 활성 상태 자동 갱신
- 현재 문제에 aria-current와 문제별 접근성 라벨 추가

3. 모바일 진행 배지 정상 연결
- 고정되어 있던 0 / 0을 실제 현재 문제 / 전체 문제 수로 갱신
- 문제 이동 시 즉시 갱신
- 진행 막대도 현재 문제 기준으로 갱신

4. 기록 탭 모바일 마감
- 전체 표현 버튼 줄바꿈 방지
- 제목·설명 영역과 버튼 폭 충돌 방지

5. 체감 난이도 모바일 표시 개선
- 모바일에서는 1~5 숫자 중심의 간결한 버튼으로 표시
- 양끝에 매우 쉬움 / 매우 어려움 안내
- 선택한 난이도를 별도 문구로 확인 가능
- 저장 값과 기존 기록 형식은 변경하지 않음

6. 설정 화면 압축
- 표시시간과 음성 속도를 모바일 2열로 배치
- 질문 음성과 지문 음성을 선택창 + 샘플 버튼 한 줄로 배치
- 카드 패딩, 항목 간격, 도움말 행간을 축소
- 터치 요소는 최소 44px 이상 유지

7. 녹음 저장·백업 화면 압축
- 저장 상태, 녹음 수, 사용 용량을 요약 영역으로 통합
- 모바일에서 저장 유지 / JSON 백업 / JSON 불러오기를 3열 한 줄로 배치
- ZIP 백업·복원은 2열 유지
- 위험 구역을 접기형 details로 변경

8. 표현 카드 편집 UX 개선
- 브라우저 prompt() 기반 4단계 편집을 인앱 바텀시트/모달로 교체
- 표현, 한국어 단서, 예문, 분류를 한 화면에서 수정
- 삭제 confirm()을 인앱 확인창으로 교체
- 표현 카드 ID와 복습 기록은 그대로 유지

9. CSS 정리
- 세 군데로 흩어져 있던 라이트 디자인 토큰을 하나의 :root 블록으로 통합
- 여러 세대의 다크 테마 변수를 하나의 :root[data-theme="dark"] 블록으로 통합
- 모바일 내비게이션 페이드와 사용하지 않는 액션바 관련 동작 제거
- 현재 라이트 글래스모피즘과 소프트 블랙 아이스의 시각 결과 유지

10. 보호 항목
- data/content.js 무변경
- 사진 12장 파일 해시 무변경
- 사진 문제의 회차·문구·순서·그룹 무변경
- localStorage 키 무변경
- IndexedDB 이름과 녹음 저장 구조 무변경
- TTS, 녹음, 평가, 프롬프트, JSON/ZIP 백업 기능 유지
